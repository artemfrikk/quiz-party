# Переносная сборка и перенос квизов: дизайн

Дата: 2026-11-19. Решения ведущего: встроить Node.js (Mac M, Mac Intel, Windows); переносить квизы и файлом, и через облачную папку.

## Зачем

Ведущий готовит и проводит квизы то на Windows, то на Mac, иногда не дома. Нужно: запуск без установки чего-либо; квизы, сделанные на одном компьютере, открываются на другом.

## Переносная сборка

- `npm run portable` собирает `dist/quiz-party-portable.zip`: приложение, рабочие зависимости (только JS, без нативных модулей), и официальный Node.js той же версии, что у разработчика, в `runtime/darwin-arm64/node`, `runtime/darwin-x64/node`, `runtime/win-x64/node.exe`.
- Сборки Node скачиваются с nodejs.org, проверяются по `SHASUMS256.txt`, кешируются в `.cache/` (в .gitignore).
- В zip у `start.command` и бинарников Mac стоит флаг исполняемости.
- `start.command` выбирает `runtime/darwin-<arch>/node`, если он есть, иначе системный node; при встроенном runtime npm не нужен.
- `start.bat` так же берёт `runtime\win-x64\node.exe`.
- Карантин macOS не обходим: один раз «правая кнопка → Открыть».

## Квиз одним файлом

- Редактор: «Скачать квиз» → `<имя>.quiz.zip` (`quiz.json` + `media/*`); «Загрузить квиз» (или перетащить .zip в список квизов) → квиз появляется в списке.
- Импорт: принимаются только `quiz.json` и `media/<имя файла>`; допускается одна общая папка верхнего уровня (если zip сделали вручную из папки); пути с `..`, абсолютные, вложенные папки в media отклоняются; имена приводятся к NFC. Имя квиза — из имени файла без `.quiz.zip`/`.zip`; если занято — « (2)», « (3)».
- Архив квиза не содержит ответов игроков и состояния игры.

## Папка квизов в облаке

- В редакторе блок «Папка с квизами»: показывает текущий путь; можно вставить путь к папке (Яндекс Диск / Google Drive / iCloud), с флажком «скопировать туда мои текущие квизы» (копируются только отсутствующие).
- Настройка своя на каждом компьютере: `data/settings.json`. Путь должен быть существующей папкой. Кнопка «Вернуть стандартную» — папка `quizzes` рядом с приложением.
- Сервер переключается без перезапуска; загруженная игра продолжает работать (её медиа берутся из новой папки, если квиз там есть).

## Мои решения

- Архивы: `yazl`/`yauzl` (потоковые, видео не грузятся целиком в память).
- Импорт до 2 ГБ, как загрузка медиа.
- Облачную синхронизацию и конфликты не обрабатываем — это делает клиент облака; README предупреждает не править один квиз одновременно на двух компьютерах.
