# Квиз-вечеринка

Свой Kahoot для компании: пульт на ноутбуке, презентация на проекторе, ответы с телефонов по QR-коду.

## Запуск

Проще всего взять **переносную сборку** `quiz-party-portable.zip`: в ней уже есть всё, включая Node.js для Windows и Mac. Ничего устанавливать не нужно — распакуйте архив и:

- **Windows:** дважды кликните `start.bat`;
- **Mac:** дважды кликните `start.command` (подробности ниже, в разделе «На Mac»).

Дальше:

1. Откроется **пульт**: `http://localhost:3737/host/`. Если система спросит про доступ к сети или входящие подключения, нажмите **«Разрешить»** (иначе телефоны не подключатся).
2. На пульте выберите квиз и нажмите **«Загрузить»**.
3. Нажмите **«Открыть экран»**, перетащите окно на проектор и кликните по нему один раз: оно развернётся на весь экран, и браузер разрешит звук у видео.
4. Гости сканируют QR-код с экрана и вводят имя. Телефоны должны быть в **том же Wi-Fi**, что и ноутбук.

Не закрывайте окно с сервером (чёрное окно на Windows, Терминал на Mac), пока идёт игра.

Без переносной сборки (только папка с кодом) нужен установленный [Node.js](https://nodejs.org) 20 или новее; при первом запуске `start.bat`/`start.command` сами поставят зависимости.

## Во время игры

- **→ или Пробел** — следующее действие (старт вопроса → показать ответ → таблица → дальше), **←** — назад.
- Видео-вопрос: ролик играет до отмеченной паузы, замирает, и появляется вопрос. После «Показать ответ» ролик продолжается.
- Кнопки под видео на пульте управляют роликом на экране (с начала, ±5 с, пауза).
- **Команды:** переключите «Команды», создайте их кнопкой «+ Команда» и перетащите людей мышкой. Двойной клик по названию переименовывает команду.
- **Отвечает капитан:** в режиме «Команды» включите «Отвечает капитан». За команду отвечает только капитан (👑), остальные голосуют на своих телефонах, а капитан видит, сколько голосов у каждого варианта. В вопросах со свободным ответом капитан видит варианты команды списком и может отправить любой одним нажатием. Капитаном сначала становится первый в команде; сменить — кнопка 👑 у игрока на пульте. Очки получает команда.
- **Очки вручную:** кнопки −10/+10/+50/+100 у каждого игрока и команды или поле «Свои очки» внизу справа (можно отрицательное число).
- **Свободные ответы** проверяются без учёта регистра, ё/е, знаков препинания и мелких опечаток, «10» = «десять». Спорный ответ можно засчитать вручную в таблице ответов на пульте.
- Если телефон уснул или страницу закрыли, человек вернётся тем же игроком со своими очками.
- Игра сохраняется автоматически. Если сервер перезапустился, на пульте появится «Продолжить прошлую игру».
- «Скачать результаты» — таблица CSV (открывается в Excel).

## Редактор

`http://localhost:3737/editor/` (кнопка «Редактор» на пульте). Всё сохраняется само.

- Слайд-**вопрос** (варианты A–D или свой ответ текстом) или **инфо-слайд** (просто текст/картинка/видео).
- Картинки и гифки — перетащите файл. Видео — файл (MP4/WebM) или ссылка на YouTube.
- Для видео найдите момент в плеере и нажмите «Начало здесь», «Пауза здесь», «Конец здесь».
- Порядок слайдов меняется перетаскиванием.

YouTube-слайды требуют интернета на ноутбуке, а некоторые ролики запрещено встраивать. Надёжнее скачать видео и добавить его файлом.

## Перенос квизов между компьютерами (Windows ⇄ Mac)

Квизы одинаково работают на Windows и Mac. Два способа:

**Файлом.** В редакторе выберите квиз → **«Скачать файл»**: получится один файл `<название>.quiz.zip` со всеми картинками и видео. Передайте его как удобно (Telegram, AirDrop, флешка, почта). На другом компьютере: редактор → **«Загрузить квиз из файла»** (или просто перетащите файл в список квизов). Если квиз с таким названием уже есть, новый получит « (2)».

**Через облачную папку** (Яндекс Диск, Google Drive, iCloud, Dropbox). Внизу слева в редакторе — **«Папка с квизами» → «Изменить…»**, вставьте путь к папке в облаке:

- Windows: Shift + правый клик по папке → «Копировать как путь»;
- Mac: правый клик по папке с зажатой Option → «Скопировать путь до…».

Редактор предложит скопировать туда ваши текущие квизы. Сделайте так на обоих компьютерах (каждый со своим путём) — и квизы будут общими. Не правьте один и тот же квиз одновременно на двух компьютерах: облако может сделать копию с конфликтом. В iCloud включите «Всегда хранить на этом Mac» для папки, иначе файлы могут оказаться не скачанными в момент игры. «Стандартная» возвращает папку `quizzes` рядом с приложением.

## На Mac

1. Перенесите на Mac `quiz-party-portable.zip` и распакуйте двойным кликом.
2. Дважды кликните `start.command`. Откроется Терминал, а затем пульт в браузере.

Если Mac пишет, что файл **нельзя открыть** («неустановленный разработчик»): кликните по `start.command` правой кнопкой → **Открыть** → **Открыть**. Это нужно один раз.

Если пишет, что **нет прав** на запуск (так бывает после копирования папки через флешку): откройте Терминал, наберите `bash ` (с пробелом), перетащите в окно файл `start.command` и нажмите Enter.

При первом запуске macOS спросит, разрешить ли «node» принимать входящие подключения. Нажмите **«Разрешить»**, иначе телефоны не подключатся. Если случайно нажали «Запретить»: Системные настройки → Сеть → Брандмауэр → Параметры → node → «Разрешать входящие подключения».

Раздать свою сеть гостям проще всего с телефона: включите на нём точку доступа и подключите к ней ноутбук и гостей.

## Обновления

Приложение обновляется само, архив заново скачивать не нужно. Если вышла новая версия, на пульте появится полоса **«Доступна новая версия → Обновить»** (нужен интернет). Обновление весит около 1–2 МБ, квизы, сохранения и настройки не меняются, сервер перезапускается сам. Обновить можно, когда игра не идёт: в лобби или после финала. Номер версии — справа вверху на пульте; клик по нему проверяет обновления заново.

В сборке нет готовых квизов — создайте свой в редакторе или загрузите файл квиза, который вам прислали.

## Где что лежит

- `quizzes/<название>/quiz.json` и `quizzes/<название>/media/` — квизы (если не выбрана облачная папка).
- `data/game-state.json` — сохранение текущей игры, `data/settings.json` — выбранная папка с квизами.
- `runtime/` — встроенный Node.js (только в переносной сборке).

## Для разработчика

```
npm install
npm test           # тесты
npm start          # сервер, порт 3737 (переменная PORT меняет его)
npm run portable   # собрать dist/quiz-party-portable.zip (скачивает Node.js с nodejs.org, проверяет SHA-256)
npm run release -- "что нового"   # выпустить версию: поднимите "version" в package.json, закоммитьте, запустите
```

`npm run release` прогоняет тесты, собирает архив обновления и переносную сборку, публикует код в репозиторий из `updateRepo` (по одному коммиту на версию) и создаёт GitHub Release `v<версия>`. Нужен вошедший `gh`. Обновление не меняет `start.bat`/`start.command` (они работают во время обновления) и папки `quizzes/`, `data/`, `runtime/`.

Пульт, редактор и API квизов доступны только с самого ноутбука (localhost), чтобы игроки не могли подсмотреть ответы.
